# Movie Flask ML1M 

**Movie Flask ML1M** is a simple movie platform built using Flask (Python).  
It uses the MovieLens 1M Dataset (ML1M)

## Getting Started

To run the application, make sure you have Python **3.10.11** installed.

Start the server with the following command:

```bash
python app.py

## RecSys Folder

The `RecSys.zip` archive included in the project contains:

- The **MovieLens dataset** used for training and testing
- The **embedding files** used for recommendations
- A Jupyter Notebook (`.ipynb`) with **qualitative analysis and data exploration**

> **Note:** Large files such as datasets and embeddings are tracked using **Git LFS** (Large File Storage). Make sure Git LFS is installed and initialized before cloning the repository.
